## 📖 Sobre

Este repositório reúne um guia completo sobre Linux voltado para profissionais de:

- DevOps
- Cloud Engineer
- Site Reliability Engineer (SRE)
- Desenvolvedores Back-end
- Desenvolvedores Full Stack
- Administradores de Sistemas

O objetivo é fornecer uma documentação organizada, prática e baseada em cenários reais de produção.

Ao final deste guia você será capaz de administrar servidores Linux, automatizar tarefas, trabalhar com Docker, Kubernetes e pipelines CI/CD utilizando as ferramentas mais utilizadas pelo mercado.

# Como utilizar

Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/linux-devops-handbook.git
```

Entre no diretório:

```bash
cd linux-devops-handbook
```

Leia os capítulos em ordem.

Cada capítulo contém:

- Conceitos
- Diagramas
- Exemplos
- Exercícios
- Laboratórios
- Troubleshooting
- Boas práticas
